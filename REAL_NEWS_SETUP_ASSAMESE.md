# HEXORA Real News Mode

HEXORA news mode searches only pages that the crawler indexed as news/article content or pages with a published date.

No fake news data and no live third-party search API is used by the core search engine.

The crawler extracts:
- publication date
- title
- description
- canonical URL
- language
- article/news metadata
- images
- video metadata

Run the crawler continuously on Railway to grow the news index.
